FAQ

Apa itu sso by keroyokan?

Launcher ringan untuk layanan UNESA. Fokusnya cuma satu: buka layanan kampus dengan cepat.

Apakah ini resmi dari UNESA?

Tidak. Ini proyek independen, tidak berafiliasi dengan UNESA.

Apakah data saya disimpan di server?

Tidak. Link dan token disimpan di browser kamu (localStorage). Cookie hanya dipakai kalau kamu memilih mode cookie, dan disimpan di server yang kamu jalankan sendiri.

Kenapa harus tempel link SSO?

Dashboard SSO memberi satu token global per render untuk semua layanan. Satu link yang masih baru bisa membuka banyak layanan sekaligus; tidak perlu copy link per aplikasi.

Kenapa link cepat kedaluwarsa?

Token SSO berumur pendek. Kalau ada layanan yang minta login lagi, buka dashboard SSO, copy satu link baru, lalu tempel di halaman Hubungkan. Satu link baru cukup untuk semua.

Bisa self-host?

Bisa. Itu salah satu tujuan proyek ini. Repo berisi Worker, server lokal, dan panduan deploy. Kalau tidak percaya instance hosted, jalankan sendiri.

Bagaimana cara deploy ke Cloudflare atau Vercel?

Lihat dokumentasi deploy button: Cloudflare Workers dan Vercel. Tombol deploy akan ditambahkan ke README saat port Svelte siap.

Apakah gratis?

Ya, dan open source selamanya.

Bagaimana cara menghapus data saya?

Buka halaman Hubungkan lalu gunakan tombol Putuskan akun, atau hapus data situs lewat pengaturan browser. Semua state ada di perangkat kamu.

Ada bug atau ide?

Buka issue di repo proyek. Sertakan langkah reproduksi dan versi yang kamu pakai.
