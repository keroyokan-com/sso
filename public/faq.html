FAQ

Apa itu sso by keroyokan? What is sso by keroyokan?

Launcher ringan untuk layanan UNESA. Fokusnya cuma satu: buka layanan kampus dengan cepat. A small launcher for UNESA services. One focus: open campus services fast.

Apakah ini resmi dari UNESA? Is this official from UNESA?

Tidak. Ini proyek independen, tidak berafiliasi dengan UNESA. No. This is an independent project, not affiliated with UNESA.

Apakah data saya disimpan di server? Is my data stored on a server?

Tidak. Link dan token disimpan di browser kamu (localStorage). Cookie hanya dipakai kalau kamu memilih mode cookie, dan disimpan di server yang kamu jalankan sendiri. No. Links and tokens stay in your browser (localStorage). Cookies are only used if you pick cookie mode, and they stay on the server you run yourself.

Kenapa harus tempel link SSO? Why paste an SSO link?

Dashboard SSO memberi satu token global per render untuk semua layanan. Satu link yang masih baru bisa membuka banyak layanan sekaligus; tidak perlu copy link per aplikasi. The SSO dashboard gives one global token per render for all services. One fresh link can open many services at once; no need to copy a link per app.

Kenapa link cepat kedaluwarsa? Why do links expire so fast?

Token SSO berumur pendek. Kalau ada layanan yang minta login lagi, buka dashboard SSO, copy satu link baru, lalu tempel di halaman Hubungkan. Satu link baru cukup untuk semua. SSO tokens are short-lived. If a service asks you to log in again, open the SSO dashboard, copy a new link, and paste it on the Connect page. One new link is enough for all.

Bisa self-host? Can I self-host?

Bisa. Itu salah satu tujuan proyek ini. Worker, server lokal, dan panduan deploy ada di repo GitHub. Kalau tidak percaya instance hosted, jalankan sendiri. Yes. That is one of the goals of this project. The Worker, local server, and deploy guide are in the GitHub repo. If you don't trust a hosted instance, run your own.

Bagaimana cara deploy ke Cloudflare atau Vercel? How do I deploy to Cloudflare or Vercel?

Lihat badge Deploy to Cloudflare dan Deploy to Vercel di README, plus panduan self-host. See the Deploy to Cloudflare and Deploy to Vercel badges in the README, plus the self-host guide.

Apakah gratis? Is it free?

Ya, dan open source selamanya. Yes, and open source forever.

Di mana kode sumbernya? Where is the source code?

Kode ada di GitHub. Bug, ide, dan diskusi lewat issues. The code is on GitHub. Bugs, ideas, and discussion go through issues.

Bagaimana cara menghapus data saya? How do I delete my data?

Buka halaman Hubungkan lalu gunakan tombol Putuskan akun, atau hapus data situs lewat pengaturan browser. Semua state ada di perangkat kamu. Open the Connect page and use Disconnect account, or clear site data in your browser settings. All state is on your device.

Ada bug atau ide? Found a bug or have an idea?

Buka issue di GitHub. Sertakan langkah reproduksi dan versi yang kamu pakai. Open an issue on GitHub. Include reproduction steps and the version you use.
