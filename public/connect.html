Tempel link SSO

  1. Buka sso.unesa.ac.id/dashboard dan login.
  2. Di HP, tekan lama salah satu aplikasi (mis. SIDIA); di desktop, klik kanan. Lalu pilih Copy link address.
  3. Tempel link-nya di bawah, lalu klik Hubungkan.

Satu link cukup untuk semua app. Kalau ada app yang minta login, tempel link baru dari dashboard.

Link hanya disimpan di browser ini, bukan di server. Jangan bagikan link ini ke orang lain.

Cookie (desktop / advanced)

Ambil cookie sesi

  1. Buka sso.unesa.ac.id/dashboard dan pastikan sudah login.
  2. Buka DevTools (F12) → tab Network, lalu refresh halaman.
  3. Klik request dashboard (tipe document).
  4. Di bagian Request Headers, copy seluruh nilai header cookie.
  5. Paste di bawah, lalu klik Hubungkan.

Mode lokal

Buka jendela Chrome untuk login otomatis (khusus server lokal).

Link disimpan di browser ini saja. Cookie (opsi advanced) disimpan di server hanya untuk mengambil daftar layanan, dan bisa diputus kapan saja. SSO Lite bukan layanan resmi UNESA.
